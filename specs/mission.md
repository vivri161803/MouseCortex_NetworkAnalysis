# Mission

## Project Purpose
To build a high-performance, modern, and minimalist web presentation for an academic report titled "Mouse Visual Cortex Connectome Analysis". 

## Target Audience
Professors and researchers looking for a fast, elegant, and data-rich reading experience.

## Design Aesthetic
Heavily inspired by **Apple's light minimalism**: clean white backgrounds, precise typography (Inter), frosted-glass panels, and smooth 60fps rendering. The emphasis is on content readability, generous spacing, and scientific rigor.

## Core Features
- A **3D Pre-Calculated Knowledge Graph** rendered as a subtle decorative background. Uses GSAP ScrollTrigger to create a "fly-through" camera effect as the user scrolls.
- An **Interactive 2D Network Graph** (D3-force) placed after the Hero section, allowing researchers to explore the connectome with drag, zoom, tooltips, and neuron-type filtering.
- **Scientific Interpretation blocks** accompanying every chart, table, and model output, translating statistical results into biological insights.
