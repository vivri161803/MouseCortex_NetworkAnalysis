# Mission

## Project Purpose
To build a high-performance, modern, and minimalist web presentation for an academic report titled "Mouse Visual Cortex Connectome Analysis". 

## Target Audience
Professors and researchers looking for a fast, elegant, and data-rich reading experience.

## Design Aesthetic
Heavily inspired by terminal aesthetics, digital minimalism, and dark mode interfaces. Focus on typography, precise spacing, and smooth 60fps rendering.

## Core Feature
A 3D Pre-Calculated Knowledge Graph rendered in the background. The graph is purely scenographic (no direct user interaction) and uses GSAP ScrollTrigger to create a stunning "fly-through" effect where the camera moves through the nodes as the user scrolls down the page.
